Usage notes for D4 toolbox:

ONLY INCLUDE D4 TOOLS IN THE MATLAB PATH WHEN RUNNING, NOT D3. Errors can
occur if older versions of files (used for D3) are included in the path.

Follow the d4_dataprocessing PDF included: this walks you through the tag
processing. For an example of how to run the toolbox, use:

d3matlab/d4nc_helper_whale.m

as a template.

use d4install/d4read to unpack 
and run d4nc_helper to process data
